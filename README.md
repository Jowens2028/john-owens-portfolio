# My First Web Page

This repository contains John Owens’s beginner HTML assignment about starting to learn IT, now styled for the CSS follow-up assignment.

Open `index.html` in a browser. It links to the separate `styles.css` file in the document head and uses semantic HTML, a heading hierarchy, an ordered list, and a descriptive alt attribute for its image. The CSS demonstrates element, class, and ID selectors; deliberate margin, padding, and borders; and a complementary navy-and-coral color scheme.

The page image is stored locally as `learning-it.jpg`, so it loads when the repository files are opened together.
