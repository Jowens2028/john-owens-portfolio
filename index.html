A beginner’s learning journal

Starting my journey in IT

I’m new to this, so I’m learning the basics one step at a time. I like that I can try a little code, open it in a browser, and see what I made.

Why I’m interested in IT

Technology is part of everyday life, and I want to understand more about how it works. Web pages are a good place for me to begin because I can practice organizing information and see how the pieces fit together.

My first steps

Here are a few things I’m working on as I get started:

  1. Learn how HTML gives a page its structure.
  2. Use headings, paragraphs, and lists to organize information.
  3. Practice making links and describing images with alt text.
  4. Learn CSS after I’m more comfortable with the HTML basics.

What’s next

Keep practicing, one page at a time

I don’t need to know everything right away. I can keep trying small projects, ask questions when I get stuck, and build my skills as I go.
