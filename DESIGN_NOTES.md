# Design notes for future styling

The milestone pages are intentionally plain HTML, with no CSS or JavaScript. These choices are a starting point for a later visual pass, not styles already applied to the pages.

## Color palette

- **Deep navy — `#1F3448`:** a steady, readable anchor for headings and navigation.
- **Warm ivory — `#F7F4EE`:** a softer page background than bright white.
- **Muted teal — `#4D827E`:** a restrained accent for links and small highlights.
- **Soft clay — `#D58B70`:** an occasional warm accent for project details.
- **Charcoal — `#30343B`:** comfortable body-text contrast.

The overall feel should be calm, curious, and personal. Use the accents sparingly so the work stays in focus.

## Type choices

- **Headings:** DM Serif Display, with a serif fallback. It gives the page a little personality without making it feel formal.
- **Body text and navigation:** Inter, with a system sans-serif fallback for clean reading on different devices.

If web fonts are not available later, the fallback fonts keep the site readable. No fonts are loaded in the current HTML-only submission.
